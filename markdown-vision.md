# Markdown Vision

Markdown Vision is a Markdown reader and editor for Windows, Linux, and macOS. Open local files to read headings, tables, images, and code blocks. Automatic text size and page width adapt to your window, and you can choose your own fonts and spacing.

Use Visual mode to edit formatted text, Markdown mode to edit the source, or Split view to see both side by side. Save changes to the Markdown file, search the document, copy code blocks, and print or save a PDF.
